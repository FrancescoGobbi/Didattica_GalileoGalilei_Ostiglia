### Unità Didattica 01 — Le funzioni in Python

**Classe 4T · Informatica · Anno scolastico 2026/2027**

L’unità introduce le funzioni in Python, collegando la spiegazione dei concetti alla sperimentazione del codice.

Argomenti dell’unità:

- [X] Che cos’è una funzione e perché usarla: il riuso del codice.
- [X] Definizione e chiamata; la funzione come oggetto.
- [X] Struttura di una funzione, parametri e argomenti.
- [X] Il parametro come etichetta locale; etichette che esistono solo durante la chiamata.
- [X] return e None: restituire non è stampare.
- [X] Il modulo e la funzione main(), ordine di esecuzione.
- [X] Funzioni che chiamano funzioni e stack delle chiamate.
