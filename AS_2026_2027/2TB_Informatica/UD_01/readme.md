### Unità Didattica 01 — Algoritmi

**Classe 2TB · Informatica · Anno scolastico 2026/2027**

L’unità introduce il concetto di algoritmo come sequenza finita di istruzioni che risolve un problema. Collega il problema all’algoritmo, al programma e alla sua esecuzione, quindi presenta le caratteristiche che una procedura deve avere per essere un algoritmo.

Argomenti dell’unità:

- [X] Dal problema all’algoritmo, al programma e all’esecuzione; origine del termine.
- [X] Algoritmi della vita quotidiana: ricetta, montaggio, indicazioni stradali, bancomat.
- [X] Caratteristiche: finito, non ambiguo, eseguibile, con dati in ingresso e risultato, generale.
- [X] Esecutore, condizione di arresto e importanza dell’ordine delle istruzioni.
- [X] Esempi: maggiore tra due numeri, media di tre voti, pari o dispari.
- [X] Procedimento per costruire un algoritmo e controllarlo con dati diversi.
